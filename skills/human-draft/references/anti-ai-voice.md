# 去 AI 味规范手册（anti-ai-voice）

本文件定义"机器腔 / AI 味"的可操作特征与改写规则。模型每次落笔都要守这些底线。根因框架与部分分类参考 Wikipedia *Signs of AI writing*、*blader/humanizer*、*petergyang/no-ai-slop*，按中文语境重写。

## 为什么会像 AI（先懂根因）

模型每一步都选"最可能接下去出现"的那句，于是总选对任何读者都成立的说法；人只为一个读者、一个主题写，所以写法不均匀、很具体。**所有 AI 味都是这种"默认选择"的下游表现**。

## 红线 12 条（SKILL.md 已列，这里给判定细节）

1. **空泛词** → 换成具体动作/数字/系统名/角色。
2. **套话开场**（"在这个……时代""随着……的发展"）→ 直接入题。
3. **导览腔**（"让我们深入探讨""下面我们来拆解"）→ 删宣告，直接写正文。
4. **假深刻收尾**（升华成比喻/格言/金句）→ 结束在最后一句具体事实，不改写成更好的比喻。
5. **挑战—展望公式**（"尽管面临……但……仍将继续……"）→ 只留具体困难和已发生的事，删展望。
6. **显著性从句**（"体现了……的深远影响""彰显了……""进一步印证了……"）→ 删从句，或换具体因果/机制/代价。
7. **无生命主语 + 名词化空转** → "数据告诉我们"→"从数据看"；"进行了优化"→"优化了"；"实现了提升"→"提升了"；"完成了闭环"→"做完了"。
8. **"不是……而是……"每篇 ≤ 1 次**，其余改直接肯定句。
9. **三连与排比** → A、B、C 每篇 ≤ 1 处；"不仅……而且……""除了……还……"拆两句陈述。
10. **防御式/假想对手** → 文中没出现的质疑者不预先反驳；"有人可能会说……但……"删。
11. **不编造** → 数字/人名/年份/引文/机制，用户或原文有才写，否则标 `【待补充】`。
12. **不磨平毛边** → 句长参差、真实犹疑（"我觉得""可能"）、作者具体判断都保留；"均匀"本身就是 AI 味。

## 通用词表（出现即处理）

| 类别 | 示例 | 处理 |
|---|---|---|
| 空泛词 | 赋能、闭环、打造、助力、深刻、显著、全面、高效、海量、极致、硬核 | 换具体动作/数字/事实 |
| 姿态词 | 值得一提的是、值得注意的是、不可否认、显而易见、毫不意外 | 直接陈述事实 |
| 膨胀词 | 极具、极其、绝不是、完全、彻底、真正的（强调义） | 删或换具体程度 |
| 展望词 | 未来可期、前景光明、值得期待、重要一步 | 删或说具体 |
| 显著性 | 里程碑、颠覆、划时代、改写历史、一流、顶级、最佳 | 直说实际发生了什么，用具体标准替代 |
| 模糊归因 | 专家认为、业内人士表示、多项研究显示、受到广泛关注 | 给出处与日期，或写清是几项、什么机构 |
| 机器人痕迹 | 当然！、好问题！、希望这能帮到你、如果需要我可以继续 | 删 |

> "强调义"指该词作修辞强调时；直陈用法（如"数据是真实的"）不算。

## 句式模板（避免的骨架）

- 假洞察开场："大多数人不知道的是""很多人都搞错了""没人告诉你" → 删开场直接说结论
- 冒号揭晓："真正的关键：……""最狠的一点：……" → 改普通句子
- 发明对比镜像："与其说是 A，不如说是 B" → 直说 B
- 回避"是/有"："作为""堪称""不失为""兼具" → 换回"是/有"
- 假范围："无论你是……还是……" → 删，只说实际受众
- 堆叠预测："可能""或许""有望"连用 → 留一个
- 反问结尾："答案不就出来了吗" → 每篇 ≤ 1 处，其余改陈述
- "X 与 Y"式空标题："荣誉与认可""优势与挑战" → 换信息量标题或并进正文
- 标题当实体下定义（清单式宽泛题名被写成专有名词开场）→ 跳过定义，直接从具体内容起

## 结构问题（段落级）

- **段落长度均匀**（每段 3–5 句像复制）→ 故意拉开长短
- **公式化开场**（先铺背景再入题）→ 以观点/事实开头
- **跑步机效应**（每段无新信息只换说法）→ 每段只留一个新事实/主张
- **段落可互换**（调换顺序无影响）→ 建立递进主线
- **过度结构化**（每段都有小标题/加粗）→ 删减
- **同义词循环**（同义反复说）→ 重复就用同一个词，别刻意换词
- **emoji 当小标题/列表图标**（✅ 优点 / ⚠️ 风险）→ 删图标，靠文字组织
- **硬凑小表格**（两三行本可一句话说完）→ 转散文

## 自检清单（交付前逐条 pass / fail）

1. 有没有空泛词、套话开场、导览腔？（有就改）
2. 结尾落在具体事实还是升华金句？（金句→改）
3. 句长参差、段落长短不一？（均匀→刻意拉开）
4. 有无无生命主语、名词化空转？（有→换回人做主、动词收尾）
5. "不是……而是……"超过 1 次？（超→改）
6. 有无显著性从句、挑战—展望公式、假深刻收尾？（有→删/改）
7. 所有数字/出处有依据或已标 `【待补充】`？（无→补或删）
8. 有没有"希望这能帮到你"等交付说明体？（有→删）
9. 作者真实犹疑、具体判断、毛边保留了？（被磨平→回退）
10. 整篇能否找出"只有这个作者才会写的话"？（一句都找不出→个性被磨平，回退）

## 永远不注入（禁止添加原文/用户没有的东西）

1. 假第一人称（"我见过很多次""依我经验"）——原文无"我"不加
2. 制造紧张（"在这个时代""史无前例"）
3. 强迫反调（"大家都错了，其实……"）
4. 表演式坦率（"说句实话""老实讲"）
5. 断句戏剧（把句子剁碎制造节奏）
6. 虚构细节（数字、人名、日期、机制——原文没有绝不编）

## 假阳性（单独出现不是可靠信号，别误伤）

弱信号单独出现时不处理：单个破折号、单个"然而/此外"、书信体问候落款、单个短句、文中的"说实话"、没有来源的主张（网上大部分内容都没来源）。**判据是信号成簇，不要抓单条**。
