# 报告写作模板（技术报告 + 行业研究报告）

适用：工程/实验/技术报告、结题报告、行业研究报告、券商研报、市场调研、投资可行性分析。

## 一、技术报告（含工程/实验/结题报告）

核心原则：**BLUF（Bottom Line Up Front）**——先给结论与建议，再给支撑。每节固定回答一个问题，整篇就是一条逻辑链。

| 章节 | 回答的问题 | 要点 |
|---|---|---|
| **Title page** | 这份报告叫什么 | 标题、作者、单位、日期；标题直陈内容 |
| **Executive Summary / Abstract** | 一句话结论是什么 | 占全文 5–10%，独立成篇，含核心发现+建议；给决策者看，尽量少术语 |
| **Introduction** | 问题是什么、为什么重要 | 背景、问题、目标、范围、假设与成功标准 |
| **Methods / Procedure** | 你做了什么 | 按时间顺序记录步骤，细节足够复现；可用列表 |
| **Results and Findings** | 你发现了什么 | 客观、用图表支撑；图用于趋势/对比，表用于精确数值，不重复两种格式 |
| **Discussion** | 这意味着什么 | 解释结果、与预期/文献对照、意义、局限 |
| **Conclusions** | 目标达成了吗 | 简短收束，回应引言提出的问题 |
| **Recommendations** | 该做什么（行动号召） | 基于发现提具体、可执行的下一步；常列表 |
| **References** | 依据从哪来 | 统一引用格式 |
| **Appendices** | 补充但不喧宾 | 原始数据、问卷、计算、图纸 |

> 不是所有报告都用全这 11 节。按长度、受众、场景删减或合并（如"结果与讨论"合并），但逻辑顺序不变。

## 二、行业研究报告（含券商研报 / 市场调研 / 投资可行性）

核心逻辑主线：**现状—问题—建议**。券商研报偏"投资要点+基本面+估值"，咨询报告偏"行业规律+战略建议"。

| 章节 | 要点 |
|---|---|
| **执行摘要（5–10%）** | 1–2 页独立成篇：核心结论、关键数据、主要建议；很多领导只读本部分 |
| **行业定义与范围** | 界定边界、细分领域；如新能源汽车是否含充电桩/电池 |
| **宏观环境（PEST）** | 政策、经济、社会、技术四维度外部影响 |
| **市场规模与增长** | 用数据说话：整体规模、增速、区域/细分、未来预测（乐观/中性/悲观多情景）；标注来源与方法 |
| **竞争格局** | 集中度、头部企业份额；波特五力（供应商/买家/潜在进入者/替代品/现有竞争者）；SWOT |
| **技术趋势** | 主流技术、新方向、迭代节点、对市场的冲击 |
| **产业链分析** | 上中下游结构、各环节价值分布、关键环节 |
| **政策环境** | 相关政策及影响 |
| **发展趋势与机会** | 未来 3–5 年走向、值得关注的细分赛道 |
| **风险提示与建议** | 主要风险（政策/技术替代/成本）+ 可操作建议；券商补投资评级与盈利预测 |
| **附录** | 数据来源、术语表、问卷 |

## 报告通用纪律

- **每写一个观点，后面必须跟数据或案例支撑**。"竞争激烈"要拿出集中度数据、头部营收对比；"消费升级"要引用人均支出、高端占比。
- **图表遵循"先见文、后见图表"**：正文先引出，再放图/表；图表标题含时间、地点、内容三要素，并标注来源。
- **标题层级一致、信息量大**：好标题让人只读标题就能跟住故事（如"2025 年 TOP3 厂商合计市占 61%，较 2023 年升 7pct"），不用"优势与挑战"这类空标题。
- **不粉饰、不夸大**：用具体标准替代"一流/顶级/最佳"；预测标明假设；风险如实写。
- **不编造数据**：无来源的数字、份额、引文一律标 `【待补充：来源】` 或删除。
